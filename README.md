# ETL Data Quality Framework

A Python ETL pipeline with data-quality checks for missing user IDs, malformed email addresses, and engagement scores outside the expected 0–100 range.

## Project contents
- `src/etl_pipeline.py` — ETL and validation workflow
- `sql/schema_ddl.sql` — warehouse schema
- `data/` — raw sample events
- `dashboards/` and `reports/` — sample outputs and findings

## Run
```bash
pip install -r requirements.txt
python src/etl_pipeline.py
```

The pipeline writes logs under `logs/`. Existing dashboard/report artifacts are sample outputs and are not automatically regenerated by every pipeline run.
